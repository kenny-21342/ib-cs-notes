## IB CS Revision Notes

Revision notes for the IB Computer Science syllabus (first assessment 2027).

A1 (Computer fundamentals) has been rewritten using *Computer Science* by MacKenty and Stephenson (Oxford, 2025), with coverage checked against the IB syllabus statements A1.1.1–A1.4.1. HL-only material is labelled. B1 also references Oxford; other sections may still contain earlier Hodder-based notes.

The notes prioritize examinable concepts and worked skills over textbook enrichment. They summarize and clarify the source rather than reproduce textbook pages. More course information is available [here](https://review.ykpao.com/).
